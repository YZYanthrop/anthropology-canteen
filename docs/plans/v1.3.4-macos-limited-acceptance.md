## 工作流及首次执行

新工作流为 .github/workflows/macos-v134-acceptance.yml，仅匹配本验收分支的 push 和验收脚本路径。
首次获批推送该分支即触发两架构，不依赖 main 上先有 workflow_dispatch。
GitHub [触发规则](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/trigger-a-workflow)
与 [runner 规格](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)已核对：
macos-15 为 arm64，macos-15-intel 为 x64。权限仅 contents:read；两个 job 不因另一架构失败而取消。
不运行原 portable-release 或三平台完整回归。只安装固定版本 playwright-core 测试客户端，使用 runner 已有 Chrome。
不安装或编译产品依赖，不构建或打包。两架构分别下载正式 ZIP 和原有校验文件，不生成替代发布包。
证据 artifact 保留 30 天，只上传报告、日志及必要合成故障材料，不上传 ZIP、测试 Keychain 或私密资料。

推送前需形成可审阅的 diff、脚本和本地提交，再请求一次“最小分支推送及两架构云端验收”授权。
不沿用历史发布推送授权。授权前只执行本地静态检查和验收工具单元测试，不启动云端。

## 验收与证据类别

| 项目 | 方法与通过条件 | 证据边界 |
| --- | --- | --- |
| 正式包 | 下载并校验；未修改包启动、页面/静态资源、合成状态保存、进程重启后读取 | published-black-box；复用原 candidate-smoke 的 release 模式 |
| A | 唯一离线 fixture worker；真实 launchctl/plutil；loaded/unloaded/disabled/loaded+disabled/absent；正常更新、记录/设置/检查失败、真实 plist 阻塞恢复失败；原定义/状态/设置/marker/journal 与重启阻写；调用计数为 0 | source-native / source-injection-native-observer；不替换正式包内 worker |
| B | 写入/sync/close/备份/替换/恢复/清理故障；真实 chmod 拒绝；子进程中断与重启阻写；保留旧来源、备份、新资料及 8/2/3 内容 | source-injection / native-filesystem；精确发布源码，离线渲染/worker 边界夹具 |
| C | 真实正常、停用、未加载、缺失；实际 plist 读取拒绝；独立标记 query 错误注入；只读不修改系统状态 | 真实系统与注入分别记录；真实 launchctl 单任务查询权限拒绝无安全条件则待验证 |
| C 页面 | 原编译 UI + 合成状态响应，检查文案、按钮可用性及只读刷新；拦截非 GET API 和非 loopback 网络 | published-ui-synthetic-status；不声称原生调度器到页面的端到端通过 |
| D | 父目录实际拒绝列举、当前资料不可读、受控扫描中目录消失、无旧版、后来出现、已有新资料不被覆盖 | 原生权限与受控竞态注入分开；正常当前资料继续可读 |
| 定时触发 | 单独真实 StartCalendarInterval，等待未来分钟；只写时间和计数的 worker 恰好执行一次 | source-native；不通过 kickstart/手动执行冒充定时 |
| 清理 | 精确 manifest 中的任务/plist/进程/临时 Keychain 删除并核对；失败报告；合成故障材料单独归档 | 不按产品前缀批量删除，不读取个人授权码 |

先检查普通 UID、用户 GUI launchd 会话及独立临时 Keychain 操作条件；缺少条件标待验证且继续独立项目。
无自动权限提升。macOS 的 disabled=false override 如无安全单项删除 API，明确记录残留；不声称系统毫无变化。
不把真实文件读取拒绝称为 launchd 查询 ACL 拒绝；不把进程重启称为整机重启。

## 停止、修复与交接

- 基线不符、源码不符或不能确定测试资源归属：停止对应写操作；不得触碰既有任务。
- 产品缺陷：保留最小复现和证据，交接后续修复版本；本任务不修改产品。独立案例仍可继续获取证据。
- 测试脚本缺陷允许修复，只重跑受影响项目；首轮失败不改写为通过。
- 仅合成资料、唯一临时任务、测试凭据；不读取个人授权码，不连接真实邮箱，不发信，不调用实时学术 API。
- 保持 8/2/3、平台和启动器边界；不扩展到 v1.4.0。
- Finder/安全弹窗、登录注销、睡眠唤醒、整机重启、真实邮箱不在本轮范围。
- 完成每架构 pass/fail/pending 清单，附运行链接、系统版本、产品/测试 SHA、关键日志和清理结果；更新 CURRENT/ACTIVE 及验证交接，本地提交后等用户验收。
- 不合并、不推送 main、不打标签、不改写发布 ZIP/校验文件/Release；有限验收不等于整个版本 Verified。

macOS 版为实验性版本，尚未完成 v1.3.4 的 macOS 原生验收，后台提醒、资料迁移及失败恢复仍存在未验证风险。升级前请保留旧版文件夹和资料备份。
