# v1.4.0：整体使用体验与可维护性路线图

- Status: `Proposed`
- Approved for implementation: no
- 更新日期：2026-09-11
- 目标版本：`v1.4.0`
- 前置条件：v1.3.3 完成并验收后，再分别讨论和批准具体工作包。

## 定位与问题

本版是较大的兼容性体验改进，不改变本地便携产品定位。本路线不授权实现、数据格式
变更或发布，不扩大 v1.3.3 的中文更新说明、左栏滚动和触摸修复范围。

- 用户会看到什么：页面、设置和通知混用技术性状态表述。
  为什么不方便：难以判断发生了什么、影响哪些内容、下一步做什么。
  技术原因：文案与状态解释分散，缺少统一表达约定。
- 用户会看到什么：窄屏展开大量关注时，文章排在很长的关注区之后；放大和辅助朗读
  的完整体验尚无全面验证。为什么不方便：查找文章与操作可能需要额外滚动和定位。
  技术原因：布局主要按宽度切换，现有测试无法完整反映实际布局和输入方式。
  具体遮挡、焦点或朗读问题须实测，不提前记为已复现。
- 用户会看到什么：README 有迁移步骤，但备份恢复和首次配置的信息分散；取消关注
  后没有撤销入口。为什么不方便：误操作或换电脑时难以确定怎样保留和恢复资料。
  技术原因：恢复能力分散在本地文件、导入工具及文章忽略状态，缺少统一使用流程。
- 用户会看到什么：相似入口在后续修改中可能出现行为差异。
  为什么不方便：反馈可能不一致，也更难及时修复。
  技术原因：审阅时 `app/page.tsx` 约 4,596 行，集中承担页面状态、关注、文章、提醒和
  保存调用。这是维护风险，不能仅以文件行数认定存在某项产品缺陷。

## 建议路线

### 阶段 1：普通中文与信息层级

- 梳理首次打开、添加关注、阅读、收藏、忽略恢复、更新检查、提醒设置和升级路径。
- 建立小型术语表：先说明结果、影响和下一步，按需展开服务名称和技术详情。
- 将必需操作与可选 API 访问凭证、邮件提醒分开，首次使用不要求配置凭证。
- 用普通用户任务走查验证入口可发现、状态可理解，保持现有中文视觉风格。

### 阶段 2：首页模块拆分与行为保护

- 先用确定性测试固定数据保护、导航、状态计数、提醒表单和弹窗行为。
- 逐步拆出关注栏、更新摘要、学者总览/详情、文章列表和操作、添加关注及提醒弹窗。
- 将本地数据访问与状态协调、更新请求、提醒表单逻辑整理为可单独测试的模块。
- 一次迁移一个边界，先保持行为一致再修改体验，避免整体重写与全面视觉变更同时进行。
- 保持字段级保存和并发保护，不退回整份数据覆盖，不重复实现各平台逻辑。

### 阶段 3：多种屏幕与操作方式

- 共同设计桌面、窄屏、短窗口和大量关注项，评估窄屏关注区的折叠与信息层级。
- 覆盖鼠标、触控板、触摸、混合输入、纯键盘、屏幕阅读器及 200%/400% 缩放。
- 检查地标、标题层级、选中状态、焦点顺序、弹窗返回、滚动区名称、状态播报、
  对比度、长文本与点击区域；减少不必要的键盘停靠点。
- Windows 和 macOS 浏览器分别记录结果；实际屏幕阅读器和触摸设备单独验收，
  自动测试通过不等于完成全面无障碍验证。

### 阶段 4：首次使用、错误、备份与恢复

- 说明数据位置、联网条件、可选配置和安全分享方法。
- 错误说明什么未完成、哪些内容仍保留及如何重试；详情按需展开，不把个人路径、
  凭证或底层错误堆栈直接作为普通提示。
- 先整理备份与恢复指引，再评估应用内入口，不预先承诺新的导入格式。
- 明确关注、文章状态、翻译、缓存、设置与提醒状态的备份范围；解释 Windows 加密
  凭据与账户绑定、macOS 授权码在钥匙串中，跨设备可能要重新输入授权码。
- 恢复或迁移前验证来源并保护目标，失败保留旧数据，完成后提供核对步骤。
- 单独评估取消关注撤销及误操作恢复，不悄悄改变原关注日期。
- 如需修改导入、包装或数据格式，另建明确工作包重新批准，不从路线图推导授权。

## 验收与发布原则

- 每阶段必须形成独立范围、失败条件、回归测试、适用浏览器/真人验收和交接记录。
- 实施运行基础 lint、构建、Node 回归和界面测试；先证明模块拆分保留旧行为，再验收
  新体验。使用合成数据与模拟接口，避免个人资料和真实公共 API。
- 保留旧数据兼容、失败保护和三平台共享实现；确需不兼容变更时重新讨论版本与迁移。
- 发布是独立授权任务，三平台来自同一不可变标签并完成原生验证。
- 工作包批准时细化顺序；不并行修改同一个尚未拆分的大页面。

## 明确不纳入

- 账户、云数据库、云同步、付费服务器和托管通知。
- 以浏览器存储替代主数据位置，或改变解压文件夹 `data/` 的归属。
- 按姓名、机构、宽泛主题或共同作者自动合并学者。
- 全网关键词信息流、新学术来源、Google Scholar 抓取。
- Electron/Tauri 重写、平台独立产品或永久产品分支。
- 未经单独授权的签名、公证、Apple 凭据配置、推送、标签和公开发布。

路线保持 `Proposed`，具体实施需另行批准。
