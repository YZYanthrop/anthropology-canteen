## 两架构基本可用门槛

在单独批准后，仅推送本分支；macos-15 arm64 与 macos-15-intel x64 从同一冻结提交构建未发布 Mac 候选包。
每包带 candidate.json、来源 SHA、版本、架构及 SHA256，保持空白资料，保存 ZIP 与报告 30 天。
只读核验最终原候选 ZIP，分开记录候选黑盒、同 SHA 源码注入、真实系统故障。

两个架构均须完成：

- 最终候选版本/来源/架构/空白资料/隐私检查，原包启动、页面、合成保存及服务进程重启持久化。
- 正常、停用、未加载、缺失、查询失败状态与文案/按钮；至少一项真实临时任务经原产品 API 至页面链路。
- 已加载且停用任务正常更新成功，保持 loaded/disabled，无意外执行。
- 已确认失败场景及此前被阻挡注入点实际到达；原定义、状态、settings、marker 恢复，或真实恢复失败提示/资料保留/重复及新进程阻写。
- 独立 StartCalendarInterval 自动触发一次；worker 只记录时间和计数，无联网。
- 精确清理自建临时任务、plist、进程和测试凭据；无法安全删除的 enabled override 如实报告，不清空用户全局配置。

测试修正后的云端重验应复用同一候选 ZIP、校验文件及源码 SHA，只更换测试 SHA 和受影响用例，不静默重建候选。
原 v1.3.4 的 B/D（macOS 15.7.9 两架构）和临时 Keychain 证据按代码相同证明复用，并明确来源为 bb78dd9。
如 runner 环境条件不满足必需项目，本轮不能判基本可用通过。
