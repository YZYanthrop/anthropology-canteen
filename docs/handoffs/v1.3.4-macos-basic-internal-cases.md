## 证据分类与范围

候选黑盒使用未替换实现的原 ZIP；source-native 使用同 SHA 调度模块与外部合成离线 worker；source-injection-native-observer 明确注入故障，其余 launchctl 为原生调用。真实 plist 读取拒绝另列系统故障。
C-native-api-ui-disabled 为真实 loaded+disabled 临时任务经未改候选 API 至未改编译页面。外部离线 payload 导致 definitionValid=false，不能据此声称发信集成通过。两架构截图已人工查看，按钮状态由 Playwright 实际 DOM 检查。
R2 每架构 34 个调度测试身份已清理，任务未加载、plist 不存在、worker 无残留；实际日历触发仅 1 次，其余更新/恢复为 0 次。

页面 server/browser、唯一 plist/LaunchAgent 已清理。未创建 Keychain 项，仅查询随机且确认不存在的测试身份；独立 Keychain 清理沿用原双架构证据。
