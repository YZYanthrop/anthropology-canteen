## Delivered

- Added a normalized snapshot of the saved reminder configuration and derived
  dirty state from the current form plus any pending credential input.
- Prevented an edited form from inheriting the saved or tested labels of the old
  configuration. Test, enable, and scheduler-migration actions stay disabled
  until edits are saved and the current values are ready.
- Explicitly states that an already-running schedule continues to use the saved
  configuration while the open form is dirty.
- Added discard confirmation for dirty reminder edits and restores the saved
  form and clears pending credential input after confirmed discard.
- Added initial focus, focus trapping, Escape close, and focus return to the
  opening control for both add-subscription and reminder dialogs.
- Added polite status semantics for ordinary notices, alert semantics for
  failures, and replaced non-action match chips with non-focusable text.
- Kept the article search visible as a full-width second top-bar row at 820 px
  and below.
- Raised explicit content metadata sizes to at least 11 px and form label and
  control text to at least 12 px without changing the Source Han Serif system.
- Updated project state and the unreleased changelog.

## Compatibility

- Reminder settings, credential storage, scheduler behavior, and all data schema
  versions are unchanged. The normalized snapshot is UI state only.
- Existing enabled schedules keep running from the saved configuration; dirty
  form values are not sent to the worker.
- No launcher, packaging, import format, platform-specific source, product
  version, hosted service, or provider changed.
- No live public API or SMTP service is used by deterministic tests.
