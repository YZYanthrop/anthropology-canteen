## 已确认产品缺陷与停止边界

`reminder-scheduler.mjs` 的 macJobDisabled 只解析 true/false；真实 macOS 15.7.9 返回 enabled/disabled。
这会将已加载且停用的任务报为 current；普通更新先 bootout 原任务，bootstrap 因停用失败，恢复也失败。
错误会如实显示 SCHEDULER_ROLLBACK_FAILED / 恢复未完成，但 journal 中 disabled=false 与实际前态不符。
具体八项失败、被阻挡的注入点和无注入最小复现见[缺陷交接](v1.3.4-macos-disabled-state-defect.md)。
未修改产品；后续修复版本须另行批准。未进入的故障路径不能用其他分支通过结果替代。

附带观察：同 loopback 的 HTTPS favicon 来自产品 metadataBase 的 HTTPS 默认值，非 CSP 升级。
UI harness 仅拦截同主机同端口 HTTPS/favicon.svg 的 GET 并单列 blockedLoopbackHttpsAssets；外网和非 GET API 仍阻断。
本轮文案/按钮通过不包含该 favicon 的成功加载；未顺手修改产品。
