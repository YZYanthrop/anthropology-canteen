自动迁移与手动导入复用 reminder-utils 的文件事务。所有目标限定在同一资料目录，记录临时文件、
备份与恢复路径后才创建临时文件；写入、同步、关闭、备份和替换失败均恢复并逐文件比对。
恢复失败保留 journal、备份和临时文件，重启后阻止自动迁移、普通 JSON 覆盖及提醒操作。
恢复确认成功才报告已恢复；清理失败单独报告，不再次替换或盲目清除恢复材料。
普通 JSON 写入与迁移共用锁，替换前比较扫描时目标字节，已有新资料不能被旧扫描结果覆盖。
旧版来源只读，手动导入使用已经验证的原始字节，格式和平台启动器不变。

测试代码覆盖准备阶段故障、后置 rename 故障、恢复再次失败、清理失败、新进程阻断、已有新资料、
手动导入来源保留及 UI 不虚报恢复。测试执行、文件占用、Windows/macOS 原生均待统一验证。
静态审阅和 git diff --check 不代表运行通过。不读取真实授权码、不发信；schema 保持 8/2/3。

限制：未完成恢复不自动重放。保留两份目录和完整资料，人工核对全部目标后再结束恢复记录；
不能仅删除 journal 解除保护。已结束但清理未完成的事务也不自动开始第二次迁移。
