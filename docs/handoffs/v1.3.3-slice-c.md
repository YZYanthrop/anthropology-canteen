## 用户能看到的变化

- 触摸或无悬停能力的设备直接显示“取消关注”，按钮实测为 60×44 像素，行间留有间隔，
  不与名称点击区域重叠；鼠标悬停及键盘进入关注行时也可发现操作。
- 取消关注后焦点移到下一项、上一项或空分组标题，不随删除的按钮消失。
- 100 项关注的测试确认只取消目标，保留其他关注日期、收藏、已读、忽略和翻译。
- 同名学者测试发现旧总览卡会复用另一人的缓存身份：页面按编号或姓名匹配，导致
  不同编号被错配到同一卡片。现在仅按稳定编号对应，回归检查同名学者的不同机构
  均正确展示，取消其中一个不会移除另一个。未修改后台身份合并、提供方或数据格式。
