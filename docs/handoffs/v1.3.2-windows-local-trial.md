## User trial procedure

1. Keep the old extracted package unchanged and closed.
2. Extract the new ZIP into a separate new folder; do not overwrite the old folder.
3. Run `import-data-from-old-version.cmd` in the new folder and drag the old
   package's `data` folder into it.
4. Start the new package and verify subscriptions, saved/read/ignored articles,
   and the reminder form. The SMTP authorization code is user-bound DPAPI
   ciphertext and remains usable only under the same Windows user account.
5. Open reminder settings once and enable or migrate the reminder task so its
   scheduler path points to the new extracted folder. Do not delete the old
   package until this succeeds and the imported data is confirmed.

If the local trial is accepted, the next task is a separate three-platform
release candidate built from one frozen commit; this handoff does not authorize it.
