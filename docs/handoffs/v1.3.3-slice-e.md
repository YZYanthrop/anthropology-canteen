## 用户会看到什么

- “迁移到当前文件夹”改为“更新后台提醒到当前文件夹”。Windows 确有需要时会显示一次权限确认；取消后明确说明任务和提醒资料都没有更改。
- 更新成功显示“后台提醒已更新到当前文件夹”。重复更新同一提醒身份不会增加任务。
- 如果普通会话无权读取任务，会说明无法自动核对并保留上次成功记录；如果发现其他身份的旧任务，只显示数量和短编号，不提供自动删除按钮。

## 实现边界

- 普通权限先按确定任务名原位更新。只有拒绝访问时才通过 UAC 启动任务小工具；应用、本地服务器和提醒程序不提升权限。
- 小工具只接收任务名、时间、经过验证的当前包路径和原登录用户身份编号，不接收邮箱、授权码或邮件内容。
- 注册后核对程序、提醒程序、工作目录、触发时间、原登录用户、交互登录和普通权限级别。失败时恢复原任务或删除本次新建任务。
- 不同任务名的旧任务没有自动删除代码；无法唯一确认来源时只报告。
- 主数据格式 8、提醒状态 2、设置 3 以及 macOS 行为、邮箱接入、启动器和导入格式不变。

## 验证结果

- `pnpm lint`：通过。
- `pnpm build`：通过。
- `node --test tests/*.test.mjs`：57 项通过。
- `pnpm test:ui`：26 项通过。
- Edge 合成浏览器：12 个窗口、触摸和键盘场景通过；首次未启动 4173 预览服务时只发生连接失败，按测试说明启动后通过并已关闭服务。
- Windows 普通会话：读取和注册任务都返回权限不足，已正确识别为需要一次权限确认。
- Windows 原生成功路径：同一随机身份从两个临时根目录连续更新，两个结果都为 `current`，第二次仍只有一个同名任务，且核对为原登录用户、`Interactive`、`RunLevel Limited`；随后按精确名称删除。
- Windows 原生取消路径：返回取消状态，安全提示正确，临时结果文件为 0，没有写任务标记。
- 完整临时 Windows x64 v1.3.3 包 smoke：空白包隐私、摘要、启动、重启持久化、导入、Windows 加密凭据、离线提醒程序和自动关闭通过；包内同名任务从原根目录更新到复制后的新根目录仍为一项并已删除。

所有原生测试只使用随机临时任务、临时授权码和模拟邮箱配置；未读取个人授权码，未连接真实邮箱。临时包、临时文件和临时任务均已删除。

## 尚未冒充完成的验证
