## Delivered

- Added an `ignored` filter to the shared article list, including a complete
  ignored count, restore controls, and immediate undo after ignoring.
- Made saved counts exclude ignored rows while preserving saved, read, and
  translation state through ignore and restore transitions.
- Kept local-data schema 8 and added the optional, uncapped `articleArchive`.
  Saved or ignored snapshots are sanitized, refreshed from the live feed,
  backfilled from old feed caches, and removed when neither state remains.
- Added honest placeholder rows for legacy saved or ignored state whose article
  metadata can no longer be recovered; users can restore or clear those states
  without editing JSON.
- Added explicit year/month/day publication precision for OpenAlex, Semantic
  Scholar, and Crossref. Duplicate records prefer a more precise valid date;
  display, ordering, and follow-date comparisons no longer invent unknown date
  components.
- Preserved publication precision in reminder state and email output.
- Updated architecture, project state, and the unreleased changelog.
